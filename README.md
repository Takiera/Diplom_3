# Stellar Burgers — UI-тестирование

**Java · Selenium · JUnit 4 · REST Assured · Page Object · Allure**

Учебный проект Яндекс Практикума.

Проверки пользовательских маршрутов Stellar Burgers: регистрация, вход, переключения разделов конструктора. UI-действия организованы через Page Object, а подготовка пользователей для сценариев входа вынесена в API.

## Подход к тестированию

- **Сквозной маршрут:** регистрация → вход → проверка email в личном кабинете.
- **Разные точки входа:** четыре пути к авторизации проверяются отдельно.
- **Негативный сценарий:** проверяется сообщение при регистрации с коротким паролем.
- **Page Object:** локаторы и действия страниц отделены от описания сценариев.
- **API-подготовка:** пользователи для проверок входа создаются через HTTP API.
- **Явные ожидания:** в ключевых переходах код ожидает нужные элементы страницы.
- **Allure:** действия представлены именованными шагами.

## Что проверяется

### Регистрация

- Успешная регистрация с последующим входом и проверкой email в профиле.
- Регистрация с паролем длиной пять символов и проверкой сообщения об ошибке.

### Вход

Переход к форме входа и авторизация:

- через кнопку на главной странице;
- через личный кабинет;
- со страницы регистрации;
- со страницы восстановления пароля.

### Конструктор

Переключение разделов «Булки», «Соусы» и «Начинки» с проверкой активной вкладки.

## Структура

```text
src/main/java/api/             # создание и удаление пользователя
src/main/java/config/          # адрес сервиса и таймаут
src/main/java/driver/          # выбор и настройка браузера
src/main/java/model/           # модель пользователя
src/main/java/pageobject/      # элементы и действия страниц
src/test/java/                 # сценарии и подготовка окружения
```

## Запуск в Chrome

Скачайте исходники `main`, распакуйте их и откройте терминал в каталоге с `pom.xml`. Для Chrome укажите выбор браузера явно:

```bash
mvn test -Dbrowser=chrome
```

Подготовка ChromeDriver выполняется через WebDriverManager и может требовать доступа к сети.

## Запуск в Яндекс Браузере

В текущем коде отсутствие `browser=chrome` выбирает Яндекс Браузер. Для этого варианта нужно заранее установить браузер и разместить совместимый `yandexdriver` в корне проекта. Драйвер не включен в репозиторий.

```bash
mvn test -Dbrowser=yandex -Dyandex.binary.path="<путь к исполняемому файлу браузера>"
```

Замените значение в угловых скобках на путь в своем окружении. Без дополнительной настройки код использует macOS-путь к браузеру.
